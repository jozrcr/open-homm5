# open-homm5

open-homm5 aims to make Heroes of Might and Magic V: Tribes of the East (with the MMH5.5 mod) better to play with friends. The first goal is fast, stable AI turns in co-op games. After that come a smarter AI and built-in online play without GameRanger. In the long run, we want a full decompilation of the game that grows into an open Heroes V engine, the way VCMI did for Heroes III. Work happens on two tracks: a function-by-function reconstruction of the original exe (each function verified to compile to the same bytes), and a hook DLL that ships improvements to the running game before the decompilation is complete.

This repository contains only our own code, notes and tools. It contains no game files, so you need your own legal copy of Heroes of Might and Magic V: Tribes of the East (for example from Steam) to use anything here.
