**open-homm5 0.2.4** builds random map templates inside the game, fixes a rare freeze of the host during computer turns, and supports MMH5.5 RC19k. It is one file, `dinput8.dll`, plus a settings file and 24 ready random map templates; the game's own files are never changed. You need the game with **MMH5.5 already installed** (RC19d or RC19k).

## New in 0.2.4

- **A template builder in the game.** On the random map screen (Solo or Multijoueur, then Générer une carte), a new **Modèles...** button opens a panel in the game's own style. It has the same choices as the web template maker:
  - a preset to start from;
  - teams and players per team;
  - neutral zones and extra towns;
  - loot and guards, also by distance from the bases;
  - size and underground.

  A map plan shows the zones in team colours. **Utiliser** sets the game's screen for you (size, players, no water, normal resources and experience, and monsters at the level that keeps the template as designed), so you just press **Créer** and **Sauvegarder**.
- **Friends need nothing.** A template's name carries its whole setup, so every PC with the add-on rebuilds the same map when joining. A friend who lacks a template now gets the game's "map failed to load" message instead of a crash.
- **Teams from the template.** On a map made for teams (2v2v2, 2 vs 2…), the lobby shows the teams as soon as you pick the map, and the team arrows still let you change them. `[rmg] recipe_teams=0` turns it off.
- **A rare freeze of the host is fixed.**
  - **The cause:** with our faster co-op timing, after a slow frame the host's computer players could take several decisions in one frame, some before their own previous moves had run.
  - **Now:** one decision per frame, after their own moves, as in the original game. Computer turns are as fast as before at normal frame rates.
  - `[ai] one_decision_per_frame`.
- **A freeze detector.** If a game ever stops answering for 20 seconds, `open-homm5.log` says where it is stuck. If that happens, wait 30 seconds before closing the game, then send the log.
- **MMH5.5 RC19k support.** RC19k sets one of the game's network timers itself, which made computer turns twice as slow with the add-on. The add-on now keeps them fast with RC19k too.
- **The camera can zoom out farther** (off by default). `zoom_out=150` under `[camera]` lets you zoom out 1.5 times as far on the adventure map; `combat_zoom_out=150` does the same in battles. Only your own screen changes.
- **French texts for the whole game** (off by default). `texts=fr` under `[lang]` shows the game's texts in French: the 3.1 patch's and MMH5.5's English texts too. It needs MMH5.5's French pack and our pack of the remaining texts in `bin\open-homm5\lang\fr\`; ask in the group for the files. Each player chooses.
- **Starting terrain that matches your faction** (off by default, host's choice). `faction_terrain=1` under `[rmg]`:
  - on random maps, every player can pick any faction in the lobby;
  - each starting zone gets its faction's ground and look (grass for Haven, sand for Academy, snow for Fortress…);
  - the map is rebuilt for a few seconds at the start, only when someone picked another faction.

  Terrain changes movement costs, which is why it is off by default.

## Also in this version (from 0.2.0 to 0.2.3)

- **Player list** on the adventure map, and a **"your turn" notification** when the game is in the background.
- **No more long autosave freeze;** quicker multiplayer (50 ms game steps when every player has the add-on).
- **Teams on random maps** and **24 ready templates** in the game's list.

## Install

1. Download `open-homm5-0.2.4.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`.
   - **Linux (Steam / Proton):** run `bash install.sh` and paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install this version.**

The installer keeps your `open-homm5.ini`. New settings work without being in it.

## Upgrading the group to MMH5.5 RC19k (optional, all together)

1. **Same day, everyone:**
   - Back up your MMH5.5 settings: copy `data\MMH55-Settings.pak` somewhere outside the game folder. The RC19d uninstaller deletes it.
   - Also move `data\MMH55-Settings - Copie.pak` out of `data\` if you have it.
2. **Uninstall RC19d** with MMH5.5's own uninstaller in the game folder. Then delete `data\index.bin` and the folder `data\RMGTemp` (MMH5.5's advice).
3. **Install RC19k** (`MMH55_RC19k.exe` from MMH5.5's ModDB page) into the game folder.
4. **Put your settings back:** copy your saved `MMH55-Settings.pak` over the new one. RC19k's default settings file is the same as RC19d's, so your old one works as it is. Every player should use the same settings file.
5. **Install open-homm5 0.2.4** again (step 2 of Install), since the MMH5.5 install may replace files in `bin`.
6. **Check:**
   - the main menu says `Version: 5.69k`;
   - the first lines of `open-homm5.log` say `open-homm5 hook DLL 0.2.4 loaded` and `game build: ToE 3.1 + MMH5.5 patches (MMH55_Utility)`.

## Check that it works

- The first line of `open-homm5.log` (in the game's `bin` folder) says `open-homm5 hook DLL 0.2.4 loaded`.
- In a co-op game, the log says `co-op timing: ON`.
- On the random map screen there is a **Modèles...** button.
