**open-homm5 0.2.1** makes multiplayer actions much quicker, and adds teams and new templates for random maps. It is still one file, `dinput8.dll`, plus a settings file; the game's own files are never changed. You need the game with **MMH5.5 already installed**.

## New in 0.2.1

- **24 ready random map templates come with the add-on.** Pick them in the game's random map list (names start with `OH-`):
  - team games: 2v2, 2v2v2, 3v3, 4v4;
  - free-for-all for 3, 4, 6 or 8 players;
  - normal or rich loot, with or without towns in the neutral zones.

  Your own templates in that folder are never touched. **Every player of a multiplayer game needs the same templates, so everyone should install the same version.**

## Also new since 0.1 (from 0.2.0, never published on its own)

- **Every action reacts faster in multiplayer:** moving heroes, entering towns, attacking, and the AI's moves too. In robot tests, AI hero moves went from 0.6 s to 0.3 s, with no desync. This works when every player runs this version: the PCs then agree on shorter game steps (50 ms) and show each result sooner. Your `open-homm5.log` says `co-op timing: ON` when that happened.
- **Teams on random maps** (and on any map where every player starts alone). The **host** chooses, in `open-homm5.ini` under `[rmg]`:
  - `lobby_teams=1`: the team arrows next to each name in the lobby pick team numbers;
  - or `teams=humans_vs_ai`, `teams=pairs` (players 1+2, 3+4...) or a list like `teams=1,1,2,2,3,3`.

  Every player gets the host's teams, even without the add-on.
- **Your own random map templates in the game's list:**
  - Make them with the template maker page, then put the `.xdb` files in `bin\open-homm5\templates\` (next to the game's exe). They appear in the generator's template list.
  - **Every player of a multiplayer game needs the same template files.**
- **A log of who everyone waits for:** every 10 seconds, `open-homm5.log` gets a `lockstep:` line showing the wait for the other players. Sending it after a game helps us tune things further.

## Install

1. Download `open-homm5-0.2.1.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`.
   - **Linux (Steam / Proton):** run `bash install.sh` and paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install this version.** If someone doesn't, the game still works, just with the game's own slower timing.

**Upgrading from 0.1.x:** the installer keeps your `open-homm5.ini`. The new settings work without being in the file; their defaults are listed in the settings file of this zip.

## Check that it works

Start the game. The first line of `open-homm5.log` (in the game's `bin` folder) says `open-homm5 hook DLL 0.2.1 loaded`. In a co-op game, the log says `co-op timing: ON from segment 50: 50 ms segments`.

## Good to know

- **If moves sometimes start with a small jump** on a slower connection, raise `view_delay_ms` under `[net]` (for example to 150 or 200).
- **Tested:**
  - robot multiplayer games on one PC (checksums compared, no desync);
  - teams chosen in the lobby;
  - our templates generated in the game.
- **Not yet tested:**
  - the new timing in a real game over the internet;
  - teams' effects inside a game (shared vision, allies);
  - the template list on the generator screen itself.
- **Uninstall:** `uninstall.bat` (Windows) or `bash uninstall.sh` (Linux).
