**open-homm5 0.1.0** is a small add-on for Heroes of Might and Magic V: Tribes of the East with MMH5.5. It makes co-op games against the AI much faster. It is one file, `dinput8.dll`, that the game loads when it starts. The game's own files are never changed.

## What it does

- **Faster co-op AI turns.** The game's network timings were made for 2006 modems. With modern ones, each AI move in a co-op game takes about 0.6 s instead of 2.5 s (robot test: two copies of the game on one PC). When **every** player has this version, the PCs also agree on shorter game steps, which brought AI moves to about 0.5 s in a real game over the internet.
- **Much less AI thinking late in big games.** The AI finds exactly the same paths, just faster: 93 s of AI thinking over 4 AI turns on a day-50 huge map became 17 s.
- **LAN games over ZeroTier** and other virtual networks. Your friend's game now shows up in the LAN list, so a Linux player can join without GameRanger.

## Install

1. Download `open-homm5-0.1.0.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`. It finds your Steam copy of the game and says what it did.
   - **Linux (Steam / Proton):** run `bash install.sh` in the extracted folder, then paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install the same version.** If someone doesn't, the game still works, just without the shorter game steps.

## Check that it works

Start the game. `open-homm5.log` appears in the game's `bin` folder, and its first line says `open-homm5 hook DLL 0.1.0 loaded`. In a co-op game, the log says `co-op timing: ON` when every player agrees.

## Good to know

- **Tested so far:**
  - two players, Windows and Linux, over ZeroTier;
  - many automatic (robot) games, with the world compared between the PCs: no desync.
  - Not yet tested: games with three or more players, and GameRanger with this version.
- **Settings:** in `open-homm5.ini` in the `bin` folder. Every setting is listed there with its default. You can leave it alone.
- **Uninstall:** `uninstall.bat` on Windows, or `bash uninstall.sh` on Linux. Only our own files are removed.
- **Problems:** please send your `open-homm5.log` file.
