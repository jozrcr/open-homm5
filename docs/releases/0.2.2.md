**open-homm5 0.2.2** removes the long freeze at the start of each round when autosave is on, and makes multiplayer actions quicker still. It is one file, `dinput8.dll`, plus a settings file and 24 ready random map templates; the game's own files are never changed. You need the game with **MMH5.5 already installed**.

## New in 0.2.2

- **No more long autosave freeze.**
  - **The cause:** to name its autosave, the game reads every multiplayer save in your profile's `Saves` folder, several times, on every PC. Each read prepares information the autosave never uses.
  - **Measured** with a folder of 17 multiplayer saves: everyone froze for **7 to 10 seconds every round**. With 0.2.2 it is about **0.2 s**; the first autosave of a session takes about 1 s.
  - Your saves are unchanged and load as before.
- **Faster autosave compression.** Saves are written about 3 times faster, and the files are about 24% bigger. They load as usual.
- **Autosave less often if you like:** `autosave_every=7` under `[save]` autosaves on the first day of each week only. The default is every day.
- **Quicker multiplayer actions.**
  - The game slows down any PC that runs ahead of the others. That rule is now adjusted to our faster game steps.
  - A finer clock.
  - In robot games, AI moves now take about 0.25 s (0.30 s in 0.2.0, 0.50 s in 0.1.1), with no desync.
- **A better log for tuning:** every 10 seconds, `open-homm5.log` shows the time from click to effect for each kind of action, and a suggested margin. Each autosave gets a line with its timings. Send your log after a game.

## Also in this version (from 0.2.0 and 0.2.1)

- **Quicker multiplayer.** When every player has the add-on, the PCs agree on 50 ms game steps and show results sooner.
- **Teams on random maps**, and on any map where every player starts alone. The host chooses: `lobby_teams=1` under `[rmg]` picks teams with the lobby's arrows, or use `teams=humans_vs_ai`, `pairs`, or a list like `1,1,2,2,3,3`.
- **Random map templates in the game's list.** 24 ready templates come with the add-on (2v2, 2v2v2, 3v3, 4v4, free-for-all), and the template maker page makes more. They go in `bin\open-homm5\templates\`. **Every player needs the same templates.**

## Install

1. Download `open-homm5-0.2.2.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`.
   - **Linux (Steam / Proton):** run `bash install.sh` and paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install this version.**

The installer keeps your `open-homm5.ini`. New settings work without being in it.

## Check that it works

The first line of `open-homm5.log` (in the game's `bin` folder) says `open-homm5 hook DLL 0.2.2 loaded`. In a co-op game, the log says `co-op timing: ON`.

## Good to know

- **Saves:** fewer multiplayer saves in your `Saves` folder still means less work for the game. Move old ones elsewhere if you don't need them.
- **If moves sometimes start with a small jump** on a slower connection, raise `view_delay_ms` under `[net]`, for example to 150.
- **Uninstall:** `uninstall.bat` (Windows) or `bash uninstall.sh` (Linux).
