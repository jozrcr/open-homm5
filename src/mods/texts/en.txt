# H5 Together texts: English
#
# The words of H5 Together's panels and messages. The add-on has English built
# in: this file is the copy translators start from.
#
# To translate (more in TRANSLATING.md, on the add-on's GitHub page,
# https://github.com/jozrcr/h5-together/blob/main/src/mods/texts/TRANSLATING.md):
#   1. Copy this file to <code>.txt, the code of your language: de.txt, ru.txt,
#      pl.txt... Save it as UTF-8 (Notepad: "Save as", Encoding: UTF-8).
#   2. Change the lines at the top (language, translated by, version).
#   3. Translate the text right of each "=". Keep the key on the left as it is.
#   4. Keep each {name} (a number or a name goes there): you may move it in the
#      sentence, but leave none out and add none. Keep the game's tags too:
#      <color=yellow>, <color_default>, <br>.
#   5. "\n" starts a new line. A line that starts with # is a comment.
#   6. Keep the texts about as short as the English ones: the panels have a
#      fixed size and cut what does not fit with "...".
#   7. Put the file in the game's bin\h5-together\texts\ folder. The add-on uses
#      it when the game is in that language, or when h5-together.ini says
#      [ui] language=<code>.
# A line you leave out, or whose {names} differ from English, shows in English;
# h5-together.log (next to the game's exe) lists those lines.
#
# language: en
# translated by: H5 Together
# for H5 Together: 0.3.0
