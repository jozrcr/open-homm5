The file
  1. Extract the zip into the game's folder, the one that holds bin and data. It adds data\RMG\Templates\ and the template file.
  2. Every player of a multiplayer game needs the same file: each PC builds the map itself from it.
  3. On the generator screen, pick the map size shown above (with or without underground, as chosen), then the template in the list.

Tested in the game: the generator builds maps from these templates. Teams: the game doesn't set teams on random maps yet; choosing them in the lobby is being worked on. Teammates' zones are joined by a lightly guarded path, but the game's generator decides where zones go and doesn't keep joined zones side by side (MMH5.5's own team templates have the same problem). Placing teammates together needs a change in the generator itself, step 3 of the plan.
